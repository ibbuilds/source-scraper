# Source Scraper 0.16.1 — durable enrichment recovery

Legacy X-only entries no longer starve public resource metadata. The additive
queue migration retires non-applicable tasks, reports unavailable raw evidence
as blocked, and preserves source timestamps and checkpoints. Each continuation
still processes at most 20 retained observations and 20 distinct public URLs.

Metadata failures stop after eight attempts. `process-pending --retry-failed true`
explicitly restarts exhausted work within a bounded continuation. Progress now
includes attempts, completed URLs, retired tasks, unavailable and blocked work,
oldest queued evidence and last successful processing time (`pending-processing-v2`).

HTML metadata reads stop at the head or the 120 KB prefix limit; a large page body
does not invalidate an already-readable title. Prefix evidence is never a claim
that the whole page was reviewed. Public DNS, redirect and credential boundaries
are retained. Safe X read retry deadlines cross the worker/CLI boundary without
response bodies or credentials; the client controls the bounded cooldown policy.

Use with Obsidian plugin 1.2.2. No model, topic vocabulary, real like or note writer
is added. Semantic accuracy still requires an independent labelled acceptance set.
