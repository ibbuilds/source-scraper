# Source Scraper 0.15.0 — integration-ready engine

This release publishes the current generic resource-quality and admission contracts, local X reader, deterministic filters and separate agent assessments in a new immutable download. It supersedes the old 0.14.0 preview without moving its tag or deleting its assets.

- `npm test` builds required CLI and optional integration artifacts before running the suite, including on a clean checkout.
- The release pipeline distinguishes unchanged maintenance versions from new releases, rejects conflicting unpublished tags, checks current main, resolves annotated tags and verifies downloaded SHA-256 checksums.
- CI package checks derive filenames from the package version instead of hardcoding 0.14.0.
- Entity JSON remains schema v1. Existing SQLite data, reviews and checkpoints are retained. Back up databases before upgrading.

Use with Source Scraper for Obsidian 1.1.0 and its verified Vault as MCP provider build. A CI pass does not attest installation on a personal device, a refreshed ChatGPT tool inventory, current X-session access, or editorial quality. No private credentials or vault data are part of release verification.
